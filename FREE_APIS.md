# 🆓 Free APIs Used in AutoShorts

> Every tool and API in this project is **100% free**. No credit card required.

## 🤖 AI / LLM (Script Generation)

| Service | Free Tier | Signup | Used For |
|---------|-----------|--------|----------|
| **Ollama** | ∞ Unlimited (local) | [ollama.ai](https://ollama.ai) | Primary AI script writer. Runs on your Mac, no internet needed. |
| **Groq** | 30 requests/min, 14,400/day | [console.groq.com](https://console.groq.com) | Fallback cloud AI. Llama 3.3 70B at insane speed. |
